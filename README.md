# Lernwerkstatt Konstrukteur

Zwei Lern-Trainer für die Ausbildung Konstrukteur/in EFZ:

- **physik/** – Physik-Trainer (eine HTML-Datei, kein Build).
- **zeichnung/** – Zeichnungstechnik-Trainer. Quelle in `zeichnung/src/`, gebaut mit `python3 zeichnung/src/build.py`.

Website: GitHub Pages (Branch `main`, Ordner `/`).

Tests (Playwright + Chrome): `python3 tests/physik_test.py`, `python3 tests/physik_t6.py`, `python3 tests/zeichnung_test.py`.

Die Aufgaben sind eigene Texte und Zeichnungen. Buchseiten und Kurs-PDFs gehören nicht ins Repo.
